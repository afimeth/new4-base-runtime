# Public-source audit repairs — 15 October 2026

N4-01: `execute()` now reads the current case corpus after `BEGIN IMMEDIATE`, under the same writer lock used to validate the approval and commit the artifact. A committed source revision cannot slip between the live read and transaction start. Completed-task replay remains idempotent; the trusted explicit-fixture override remains available.

N4-02: the preparation event is derived from the resulting task state, including computed math results and failed topology requests.

N4-03: the Go worker accepts only `[calculate|sum|total] amount (+ amount)* USD|EUR` (optional verb, case-insensitive, whitespace allowed). Unsupported operators, extra prose, malformed numbers and scientific notation are rejected instead of having their numbers silently summed. Existing integer minor-unit, decimal, count and amount limits remain.

`tests/test_audit_regressions.py` adds ten test methods covering the writer-lock interleaving, a second real SQLite writer, frame/event agreement, explicit fixture compatibility, replay, supported additions and unsupported expressions. These tests use the real Go worker. The evaluation source-hash manifest includes the new test file.

Historical committed reports and their timestamps are unchanged. CI checks the historical report in a separately pinned checkout and generates/verifies a fresh report against current source. Historical measurements are not asserted to describe the repaired source. Full-suite results must be read from the CI run for the reviewed commit; local targeted test execution is not a substitute for that matrix.

No network effect, external authority or production reliability guarantee is added by these repairs.
