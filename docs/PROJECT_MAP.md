# Project-map lens

The map derives from the same transactional case snapshot as tasks, sources and receipts. It is an operational workflow map, not an invented product roadmap. Source, prepared, reviewed and committed counters identify their exact basis. No subjective percentage is generated.

Parts show Not started, Awaiting approval, Ready, Hold, Context changed, Done or Cancelled. A source/dictionary revision marks a pending proposal stale and removes it from the approval-ready view. An approved current proposal is the first next-step candidate; independent work can remain actionable while other tasks await a call.

Needs your call lists exact-payload approval requests. Silence or elapsed time never supplies approval. Recent changes link directly to retained receipt evidence, including its hash and prior hash. The map has no separate mutable state, model inference or background drawing agent.
